What is PlateHound and what is it like to use?

Long image

A

Answer

PlateHound is a working Python command-line prototype. You give it a Florida plate as text or an image. It prints a vehicle spec card, a sales segment and a pitch line, and saves them to a local SQLite file you can filter and export.

  1. It runs today with Python and Pillow; the 14 bundled tests pass and every command below ran on the built-in sample plates.1
  2. Vehicle specs are real only for 8 built-in sample plates: each maps to a hard-coded VIN that it decodes with the public NHTSA vPIC API.2
  3. Any other plate gets a placeholder vehicle picked by a hash from a list of 6 models. There is no real plate-to-owner or plate-to-vehicle lookup.3
  4. Without the tesseract program installed, scan-image reads the plate text stored inside the PNG file, not the pixels.4

  1. Plate text or image ↗

    Run platehound scan "FL-76BCDE" or platehound scan-image samples/plates/SUNSHN.png, with an optional --note.

  2. Read and clean plate ↗

    It strips the FL prefix, fixes look-alike characters such as O/0 and checks Florida plate patterns.

  3. Sample plate? ↗

    Only the 8 sample plates have a VIN in the code.

  4. Decode VIN via vPIC ↗

    The VIN goes to NHTSA vPIC with a 3-second timeout; a cached copy is used when offline.

  5. Placeholder vehicle ↗

    Any other plate gets one of 6 stock vehicles chosen from the plate's characters.

  6. Pick segment and pitch ↗

    Rules on fuel, make, model and body pick one of 5 segments and a fixed pitch line.

  7. Save to SQLite ↗

    The lead is stored in platehound_leads.db; scanning the same plate again adds a sighting.

  8. List, stats, export ↗

    Filter with search --segment, see counts with stats, export CSV, JSON or an HTML dashboard.

2

What goes in?

You type a plate string, or point it at an image. generate-plates draws 8 synthetic Florida-style plates into samples/plates/ for testing.

3

What do you get back?

The confidence figure is a formula, not a model score. It is a fixed 0.96 for images or 0.92 for text, times 0.95 for a 6–7 character plate. Ten sightings come from 8 plates because two were scanned twice in this run.

Privacy and use

PlateHound stores the plate text and your free-text note in a plain SQLite file. A note such as a street name can turn a lead into location data about a person. Collecting real plates for marketing may be regulated where you live. Check the rules before pointing it at real vehicles.
